소원물류 기사앱

홈 화면에 설치하고 알림을 켜면
공지·정산·리스트 새 소식을 바로 받아요 🔔

⚠️ 지금은 카톡/인앱 브라우저예요

여기서는 앱 설치·알림이 안 됩니다.
아래 버튼으로 크롬에서 다시 열어주세요.
🍎 아이폰: 화면 우측 하단/상단 메뉴(⋯ 또는 ᐁ) → Safari로 열기 → 설치를 진행하세요.
🤖 안드로이드
🍎 아이폰
✅ 앱이 이미 설치되어 실행 중입니다.

🤖 안드로이드 설치

1
① 앱 설치 버튼을 누르면 설치 → 이어서 알림 허용 창이 뜹니다. (버튼이 없으면 크롬 우측 상단 ⋮ → 홈 화면에 추가 / 앱 설치)
2
알림 허용을 눌러주세요. 이게 있어야 공지·정산·리스트 알림이 옵니다.
3
홈 화면에 생긴 소원물류 기사앱 아이콘으로 실행 → 로그인하면 끝!
※ 설치 버튼이 비활성화면 크롬 메뉴에서 "홈 화면에 추가"를 눌러주세요.

🍎 아이폰 설치

1
반드시 Safari(사파리)로 이 페이지를 여세요. (카톡이면 위의 사파리로 열기 먼저!)
2
하단 공유 버튼 → 홈 화면에 추가 → 오른쪽 위 추가.
3
홈 화면 아이콘으로 앱을 열고 로그인하면 알림 허용 창이 뜹니다. 허용을 눌러주세요.
※ 아이폰은 iOS 16.4 이상 + 홈 화면에 추가한 앱에서만 알림이 됩니다.
문의는 관리자에게 연락해주세요.

🍎 아이폰
✅ 앱이 이미 설치되어 실행 중입니다.

🤖 안드로이드 설치

1
앱 설치 버튼을 누르세요. (버튼이 없으면 크롬 우측 상단 ⋮ → 홈 화면에 추가 / 앱 설치)
2
홈 화면에 생긴 소원물류 기사앱 아이콘으로 실행합니다.
3
아래 알림 허용을 누르고, 앱에서 로그인하면 끝!
설치 버튼이 비활성화면, 크롬 메뉴에서 “홈 화면에 추가”를 눌러주세요.

🍎 아이폰 설치

1
반드시 Safari(사파리)로 이 페이지를 여세요.
2
하단의 공유 버튼 을 누릅니다.
3
홈 화면에 추가를 선택 → 오른쪽 위 추가.
4
홈 화면 아이콘으로 앱을 열고 로그인하면, 알림 허용 창이 뜹니다. 허용을 눌러주세요.
※ 아이폰은 iOS 16.4 이상에서, 홈 화면에 추가한 앱으로 열어야만 알림을 받을 수 있어요.
문의는 관리자에게 연락해주세요.
